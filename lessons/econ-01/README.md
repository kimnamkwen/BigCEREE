# 1주차(경제성평가 연구 개요) 수업 자료 폴더

이 폴더의 파일은 `classes/economic-evaluation/01-introduction/present/` 수업 화면에서 자동으로 불러옵니다.

| 파일 | 용도 |
|---|---|
| `econ-01-slides.pdf` | 상단 **원본 PDF** 버튼 |
| `original-p01.webp` ~ `original-p28.webp` | 각 절의 **원본 슬라이드 보기** |

공개용 PDF와 슬라이드 이미지는 원본 1강 PDF의 1–28쪽으로 만들었습니다.

- 29쪽(Q&A): 연락처가 있어 제외
- 2쪽: 프로필 사진·전화번호·이메일을 지운 이미지로 교체
- 10·11·12쪽: 이용 허락을 확인하기 어려운 클립아트를 같은 내용의 문구로 교체
- 16쪽: 학술지 표(Kim SY 등, 2000)를 '논문 참조' 안내로 교체
- 17쪽: 지폐 클립아트 삭제, 독감 예방접종 100만 달러당 생명연수 7,750 → 7,692 수정
- 18쪽: 교재(Drummond 4판 Ch.1) 표를 '교재 참조' 안내로 교체

다시 만들 때는 저장소 밖 `_work/make_slides.py`와 `_work/spec01.json`을 사용합니다.
