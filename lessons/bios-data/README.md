# 보건의료통계학 공통 실습 자료

이 폴더는 `classes/biostatistics/<NN-주제>/present/` 수업 화면의 R 실습에서 함께 씁니다.

| 파일 | 용도 |
|---|---|
| `vas.csv` | 합성(synthetic) 실습 자료 60명 × 9변수. 실제 환자 자료가 아닙니다. |
| `make_vas_synthetic.R` | `vas.csv`를 만든 R 코드 (난수 seed 고정, 다시 만들 수 있음) |
| `bios-webr.js` | 수업 화면용 webR 준비 스크립트. `vas.csv`를 webR 작업 폴더에 넣어 `read.csv("vas.csv")`로 읽게 함 |

## 변수

| 변수 | 설명 |
|---|---|
| `id` | 대상자 번호 |
| `treat` | 군 (0 = 대조군, 1 = 치료군), 각 30명 |
| `sex` | 성별 (0/1) |
| `age` | 나이 (20–65세) |
| `ses` | 사회경제적 수준 (1 = 상, 2 = 중, 3 = 하) |
| `cost` | 의료비용 (원) |
| `qol` | 삶의 질 효용값 (0–1) |
| `vas_1` | 치료 전 통증 VAS (0–10, 낮을수록 좋음) |
| `vas_2` | 치료 후 통증 VAS |

## 사용

- RStudio: 이 파일을 내려받아 작업 폴더에 두고 `vas <- read.csv("vas.csv")`
- 수업 화면: 실습 칸의 **실행** 버튼을 누르면 같은 코드가 브라우저에서 실행됩니다.
