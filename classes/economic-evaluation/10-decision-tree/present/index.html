10. Decision tree model

Decision Tree Modelling · 경제성평가 10주차

1. Decision tree 개요

의사결정나무는 결정 마디·확률 마디·종결 마디와 서로 배타적인 가지로 이루어지고, 경로 확률은 가지의 확률을 곱해 구합니다(9주차). 분석은 ① 문제 구조화 → ② 나무 만들기 → ③ 기저분석(기댓값, 정보의 가치) → ④ 민감도 분석(일원·이원·임계값) 순서입니다.

2. 사례: 일본뇌염 유행 예상 지역의 살충제 살포

이 사례는 Sue Goldie와 Lee의 강의 예제를 바탕으로 합니다.

모기가 옮기는 뇌염의 유행이 보고되었습니다. 당국은 인구 100,000명 도시에 살충제를 뿌릴지 정해야 합니다.

  • 유행 확률은 20%이며, 유행하면 2주 동안 인구의 2%가 뇌염에 걸립니다. 그중 30%는 사망하고 70%는 후유증을 안고 회복합니다.
  • 살충제를 뿌리면 유행하더라도 발병은 0.1%로 줄지만, 살충제 독성으로 노출자의 0.1%가 사망합니다(뇌염 생존자는 살충제로 사망하지 않는다고 가정).
  • 유행 여부를 검사하면 확실히 알 수 있지만 1주일이 걸리고, 그동안 인구의 1%가 뇌염에 걸립니다.

3. Decision tree 모델링 분석

1) 문제 구조화

항목내용
시작점도시의 뇌염 유행 가능성
분석 기간2주
대안살포 / 검사 후 결정 / 살포 안 함
확률유행 0.2, 살포 시 뇌염 0.001, 살포 안 할 때 뇌염 0.02, 검사 기간 중 뇌염 0.01
결과(사망 확률)뇌염 사망 0.3, 비감염자의 살충제 사망 0.001, 살포하지 않으면 0

원본 슬라이드 15쪽의 “살충제 투여 안 하는 경우 뇌염 발생확률 0.2”는 문제(2%)와 18쪽 나무에 맞춰 0.02로 바로잡았습니다.

2) 나무 만들기

살포·검사·살포 안 함의 세 가지에서 유행/비유행, 뇌염/비뇌염 가지를 그립니다. 검사 가지에서는 유행이면 살포, 비유행이면 살포하지 않습니다. 각 가지 끝에 사망 확률을 붙입니다.

3) 기저분석

대안기대 사망 확률기대 사망자 (10만 명)
살포0.2×(0.001×0.3 + 0.999×0.001) + 0.8×0.001 = 0.0010598106명
검사0.2×(0.01×0.3 + 0.99×0.001) + 0.8×0 = 0.00079880명
살포 안 함0.2×0.02×0.3 = 0.0012120명

4) 민감도 분석

살충제 사망 확률 p를 바꿔 봅니다(신뢰구간 0.0005–0.002). 살포와 살포 안 함의 사망자가 같아지는 p는 0.00114이며, 세 대안을 함께 보면 p < 0.00067이면 살포, 0.00067–0.00303이면 검사, p > 0.00303이면 살포 안 함이 최선입니다(임계값 분석). 실습 1에서 확인합니다.

5) 정보의 가치

검사 정보가 정확하다면, 검사로 얻는 정보의 가치는 살포(106명)와 검사(80명)의 차이인 26명입니다. 확률적 분석에서는 반복마다 최선의 대안을 골랐을 때의 기대 순편익과, 현재 정보로 고른 대안의 기대 순편익의 차이가 완전정보의 기대가치(EVPI)입니다. 실습 2에서 계산합니다.
