5. 비용효과분석

Cost-Effectiveness Analysis (CEA) · 경제성평가 5주차

1. 비용효과분석 개요

CEA는 결과를 혈압(mmHg), 혈당, 콜레스테롤, 합병증 발생률, 연장된 수명 같은 자연단위로 측정합니다. 결과 지표가 같아야만 비교할 수 있어, 건강 프로그램과 환경 프로그램처럼 다른 공공사업과 직접 비교하기는 어렵습니다.

방법특징
비용효용분석 (CUA)임상효과 개선, 부작용 감소, 삶의 질 개선처럼 여러 측면을 하나의 지표(QALY)로 평가
비용결과분석 (CCA)대안별 비용과 결과를 합치지 않고 나열해 의사결정자가 직접 비교·교환. 교환(trade-off)이 명시적이지 않다는 문제가 있어 요즘은 CUA를 선호

결과 지표는 치료의 궁극적 목표를 잘 반영해야 합니다. 임상적 개선으로 이어지기 어려운 단순한 생화학 표지는 부적절하며, 시험 기간에 측정하기 어려운 최종 결과는 모델링으로 추정합니다.

2. 효과분석

1) 최종 결과 vs. 중간 결과

  • 최종 결과(final intended outcome): 예) 항고혈압제의 사망률·뇌졸중 감소
  • 중간 결과(대리 결과): 예) 혈압 감소. 최종 결과에 가까울수록 유용합니다.
  • 중간 결과는 ① 최종 결과와의 관련성이 확립되었거나 ② 그 자체로 가치가 있을 때 쓸 수 있습니다. 가장 중요한 것은 의사결정자의 관심사에 맞는가이며, 급여 결정에 쓰려면 효과 한 단위 증가의 임상적·경제적 의미를 설명해야 합니다.
  • CEA 효과 지표의 예: 혈압 감소(mmHg), 혈청 콜레스테롤 감소율, 발견된 DVT 사례 수, 천식 무증상일, 얻은 생존연수.
  • 통계적 유의성뿐 아니라 효과의 크기가 임상적으로 의미 있는지 봅니다. 암 선별검사에서 ‘발견된 사례 수’는 적절한 지표가 아닙니다. 선별검사의 목적은 조기 이환과 사망을 막는 것이고, 효과는 발견된 암의 유형과 병기에 따라 다르기 때문입니다.

2) 효과 자료원의 이슈

  1. 질: 무작위 배정이 가장 중요하지만, 경제성평가에는 RCT 외 다양한 자료원이 필요합니다.
  2. 적절성: 임상 자료가 분석 상황과 얼마나 가까운가. 질과 적절성의 기준은 서로 어긋날 수 있습니다(효능 vs. 효과).
  3. 포괄성: 사용한 임상 자료가 의학 문헌 전체를 대표하는가.
근거 수준연구권고 등급
I결과가 명확한 대규모 무작위시험(오류 위험 낮음)A
II결과가 불확실한 소규모 무작위시험(오류 위험 중등도 이상)B
III비무작위, 동시대 대조군C
IV비무작위, 역사적 대조군D
V대조군 없음, 증례 연구E
  • RCT: 참가자를 무작위로 실험군·대조군에 배정. 무작위화, 이중맹검, ITT 분석(분모 = 무작위 배정된 전원) 여부로 질을 평가합니다.
  • 환자-대조군 연구: 질병이 있는 군과 적절한 대조군의 과거 노출 정보를 비교합니다.
  • 코호트 연구: 처치군과 비처치군의 결과를 비교하되, 무작위 배정이 아니라는 점이 RCT와 다릅니다.

3) 메타분석

기존 연구 결과를 통계적으로 결합하는 방법입니다. 시험 결과가 서로 모순되거나 개별 시험이 너무 작을 때 필요하며, 먼저 양적 통합이 바람직한지 검토합니다. 단계: 체계적 검색 → 선정기준 정의 → 문헌 선정 → 자료 요약 → 통계 분석(이질성 검증 포함). 개별 연구의 원자료를 모아 분석하는 것도 메타분석입니다.

  • 이질성: 임상적·통계적 이질성을 고려하며, χ² 검정(Q 통계량)과 숲 그림으로 확인합니다. 랜덤효과모형을 썼다고 이질성 문제가 해결되는 것은 아니며, 하위군 분석·메타회귀로 원인을 찾아야 합니다.
  • 고정효과모형: 모든 연구가 같은 효과크기를 추정한다고 가정하며, 표본이 큰 연구에 가중치가 더 갑니다.
  • 랜덤효과모형: 연구 간 분산과 연구 내 분산을 모두 인정해 더 보수적이고 신뢰구간이 넓습니다. 연구 간 분산이 크면 큰 연구와 작은 연구의 가중치가 비슷해집니다. 이질성이 거의 없으면 두 모형의 결과는 같습니다.
  • 민감도 분석: 선정기준, 특정 연구 포함·배제, 미발표 문헌 포함 여부, 통합 방법을 바꿔 결과가 안정적인지 확인합니다.

4) 효과의 할인

  • 반대 견해: 사람이 건강을 투자하거나 거래한다고 보기 어렵고, 미래 세대의 건강에 낮은 가중치를 주게 되며, 실증적으로도 사람들은 건강을 돈과 다른 율로 할인합니다.
  • 찬성 견해: 효과를 할인하지 않으면 추론이 비일관적이 되어 결정을 계속 미루게 됩니다(비용만 할인하면 항상 내년에 시작하는 편이 유리). 보건의료를 다른 부문과 다르게 다루면 전체 자원배분이 일관되지 않습니다.
  • 현재 원칙: 비용과 효과를 같은 율로 모두 할인하는 것이 대세입니다. 영국은 한때 비용 6%·효과 1.5%를 권고했다가 둘 다 3.5%로 바꾸었습니다. 국내 의약품 경제성평가 지침의 할인율은 4.5%(2021년)이며, WHO CEA 지침은 3%를 기본으로 비용 6%·효과 0%를 민감도 분석에 씁니다.

3. 비용효과분석 결과 제시

  • 평균 비용효과비(CER = C/E): 대안들이 서로 독립적일 때 씁니다.
  • 증분 비용효과비(ICER = (C1 − C0) / (E1 − E0)): 대안들이 서로 대체 관계일 때 씁니다. 규모수익 불변과 가분성을 가정하며, 규모에 따라 비용효과비가 달라지면 규모가 다른 프로그램은 서로 배타적인 대안으로 정의합니다.

ICER 계산 순서

  1. 비용 순으로 대안을 나열합니다.
  2. 비용은 오르는데 효과는 같거나 떨어지는 대안(강한 열등, strongly dominated)을 뺍니다.
  3. 차례로 ICER를 구합니다.
  4. 다음 대안보다 ICER가 큰 대안(약한 열등 = 확장우월, weakly dominated)을 빼고 ICER를 다시 구합니다.

순편익 — 임계값 NT에서 ΔC/ΔE < NT는 다음과 같습니다.

순화폐편익 NMB = NT·ΔE − ΔC > 0   |   순건강편익 NHB = ΔE − ΔC / NT > 0  → 비용효과적
