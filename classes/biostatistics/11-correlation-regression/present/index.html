11. 상관분석·회귀분석

Correlation and regression · 보건의료통계학 11주차

1. 상관분석

두 연속변수 사이의 선형 관계의 정도를 상관계수로 나타내고 유의성을 검정합니다. 모집단 상관계수 ρ, 표본 상관계수 r, −1 ≤ ρ ≤ 1이며 부호는 방향, 크기는 강도입니다.

r = Cov(X, Y) / √{Var(X)·Var(Y)},   t = r √{(n − 2)/(1 − r²)}  (자유도 n − 2)

가정: 정규성, 이변량 정규성, 등분산. H0: ρ = 0, HA: ρ ≠ 0. 순위를 쓰는 Spearman·Kendall 상관도 있습니다. 예) 비용(cost)과 삶의 질(qol)의 상관.

2. 단순선형회귀분석

종속변수(결과)와 독립변수(예측변수)의 관계를 회귀계수로 추정하고, 모형과 회귀계수의 유의성을 검정합니다.

  • 가정: 선형성, 정규성, 등분산, 독립성
  • 최소자승직선: Σ(Yi − Ŷi)²을 최소로 하는 직선 Ŷ = β0 + β1X, 기울기 b = Cov(X, Y)/Var(X)
  • 모형 전체: 설명력 R² = SSM/SST, F 검정(H0: 모든 회귀계수 = 0)
  • 회귀계수: t = β1/SE(β1), 자유도 n − 2 (Wald test)

RStudio 스크립트는 olsrr 패키지의 ols_regress()로 표를 정리합니다. 아래 실습은 기본 함수 summary()와 anova()로 같은 내용을 봅니다.
