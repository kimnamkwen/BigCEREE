14. 비모수검정·표본수 계산

Nonparametric tests and sample size · 보건의료통계학 14주차

1. 비모수 통계의 개념

모수적 통계는 표본이 속한 모집단의 분포를 가정하고, 비모수 통계는 그 분포를 가정할 수 없을 때 씁니다. 표본이 30 이상이거나 정규분포를 따르면 모수적 방법이 바람직하고, 서열이나 분류 자체가 목적이면 비모수 방법이 좋습니다.

  • 순위검정: 원자료 대신 순위로 중위수를 검정
  • 순열검정: 분포 가정 없이 두 표본이 같은 모집단에서 왔는지 검정
  • 부트스트래핑: 반복 표본추출로 얻은 값들로 오차 범위를 파악
모수적 검정비모수 검정
Paired t testWilcoxon signed rank test
Independent t testWilcoxon rank sum test (Mann-Whitney U)
ANOVAKruskal-Wallis test
Pearson correlationSpearman correlation

2. 부호검정, 부호순위검정, 순위합검정

  • 부호검정(sign test): 중위수가 특정 값인지. 자료가 20 미만이면 이항분포로, 20 이상이면 z = {(k + 0.5) − 0.5n}/(0.5√n)로 p값을 구합니다.
  • 부호순위검정(signed rank test): 짝지은 자료의 차이에 절댓값 순위를 매기고 부호를 붙여 W+, W− 중 작은 값을 W로 씁니다. paired t의 비모수 방법
  • 순위합검정(rank sum test): 두 독립군 자료를 합쳐 순위를 매기고 U = min(U1, U2)로 검정. 독립 t의 비모수 방법

3. 표본 수 계산

독립된 두 군의 평균 차이를 검정하는 임상시험의 표본 수입니다. 1종 오류(α = 0.05), 2종 오류(β = 0.2, 검정력 80%), 두 군의 추정 평균과 표준편차(선행연구, 예비연구)가 필요합니다.

n1 ≥ 2(zα/2 + zβ)² σ² / (μ1 − μ2)²,   σpooled = √{(SD1² + SD2²)/2}

예) 평균 7.1과 13.93, 표준편차 11.24와 11.6 → 군당 약 44명. G*Power 프로그램으로도 계산하고, 탈락률(예: 10%)을 더해 모집 수를 정합니다.

4. 임상시험 통계분석 실습 표

최종 과제 표: (1) 두 군의 기저 특성, (2) 삶의 질·비용·결과 변수 간 상관, (3) 두 군의 치료 전후 개선(군내 paired t, 군간 independent t), (4) G*Power 표본 수 계산(1차 결과변수, α = 0.05, β = 0.2, 탈락률 0.1). 지금까지의 실습 코드로 vas.csv에서 같은 표를 만들어 봅니다.
