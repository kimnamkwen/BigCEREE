1. Excel과 난수로 분석 자료 만들기

Excel의 RANDBETWEEN()과 RAND()로 변수별 최솟값·최댓값 범위의 난수를 만들어 연습용 자료를 만들 수 있습니다. 예) 0.5~1 사이 삶의 질: ROUND(0.5 + RAND()*(1-0.5), 3).

이 수업의 실습 자료 vas.csv도 같은 생각으로 R 난수로 만든 합성 자료입니다(생성 코드).

2. 의학 분야 통계분석 프로그램

Excel, SPSS, SAS, STATA, R, Python이 주로 쓰입니다. 이 수업은 무료이고 재현 가능한 분석이 쉬운 R을 씁니다.

R의 특징

  1. 데이터의 효율적인 조작과 저장
  2. 배열·행렬 연산
  3. 다양한 데이터 분석 도구
  4. 분석과 표현을 위한 그래픽 도구
  5. 프로그래밍 언어로서 S 언어 지원

R이라는 이름은 두 저자(Robert Gentleman, Ross Ihaka)의 첫 글자와, 1976년 Bell Lab에서 개발된 S 언어에서 왔습니다. GNU GPL에 따른 자유 소프트웨어로, 어떤 목적으로든 실행하고, 고치고, 다시 배포할 수 있습니다.

RStudio와 Posit Cloud

RStudio는 스크립트 창(위)과 콘솔 창(아래), 환경·그래프 창으로 구성됩니다. 설치가 어려우면 브라우저에서 쓰는 Posit Cloud를 이용합니다.

3. R의 데이터 종류

종류설명
Vector1차원 자료. 숫자형, 문자형, 논리형(logical)
Factor범주형 자료(예: 남성 = 1, 여성 = 0)
Matrix2차원 자료, 행렬 연산용
Array3차원 이상, 배열 연산용(Python의 tensor와 비슷)
List여러 형태가 섞인 묶음
Data frame통계분석에 주로 쓰는 다변량 자료 구조
