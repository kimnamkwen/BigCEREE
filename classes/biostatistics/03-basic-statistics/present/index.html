3. 기초통계학

Basic statistics and probability · 보건의료통계학 3주차

1. 통계학의 개념

통계학은 자료를 수집·정리·요약하고, 일부 자료(표본)만 보고 전체(모집단)의 특성을 추측하는 학문입니다.

  • 기술통계학: 자료를 정리하고 요약 / 추측통계학: 표본으로 전체를 판단
  • 변수: 양적 변수(신장, 체중, 나이), 질적 변수(사회경제적 수준 상·중·하, 진단명)
  • 확률변수: 이산형(환자 수, 충치 수처럼 0, 1, 2…), 연속형(신장, 체중)
  • 모집단과 표본: 유한·무한 모집단, 표본은 모집단의 일부. 표본에서 구한 값은 통계량, 모집단의 값은 모수

2. 자료의 정리

자료를 도수분포표와 히스토그램으로 정리하고, 중앙집중성(평균·중앙값·최빈값)과 산포성(분산·표준편차)으로 요약합니다.

모분산 σ² = Σ(xi − μ)² / N,   표준편차 = √분산,   변동계수 CV = 표준편차 / 평균 × 100

슬라이드 13쪽 예: A = (2, 3, 4)와 B = (1, 3, 5)는 평균이 모두 3이지만 분산은 0.667과 2.667(N으로 나눈 값)로 B가 더 흩어져 있습니다. R의 var()는 표본분산(n − 1로 나눔)이라 1과 4가 나옵니다(실습 2).

3. 확률이론

  • 기본 성질: P(E) ≥ 0, 모든 사상의 확률 합 = 1, 배타적이면 P(Ei 또는 Ej) = P(Ei) + P(Ej)
  • 경우의 수: 팩토리얼 n!, 순열 nPr = n!/(n − r)!, 조합 nCr = n!/{r!(n − r)!}, 같은 것이 있는 순열 n!/(p!q!)
  • 조건부확률: P(B|A) = P(A∩B)/P(A). 예) 의사 50명 중 30세 이상 10명 → 10/50 = 0.2
  • 가산법칙: P(A∪B) = P(A) + P(B) − P(A∩B), 승산법칙: P(A∩B) = P(A|B)·P(B)

4. Bayes 정리와 진단검사

검사 전 확률(사전확률)과 검사의 민감도·특이도로 검사 후 확률(사후확률)을 구합니다.

  • 민감도(Sensitivity) = P(양성 | 질병 있음), 특이도(Specificity) = P(음성 | 질병 없음)
양성일 때 사후확률 P(D|+) = P(D)·Sens / { P(D)·Sens + (1 − P(D))·(1 − Spec) }

오즈로 계산할 수도 있습니다: 사전 오즈 × 우도비(LR) = 사후 오즈, 오즈 = p/(1 − p), p = 오즈/(1 + 오즈).

예제 1: 스트레스와 피로를 호소하는 50세 남성, 경험상 우울증 확률 40%. 민감도 60%, 특이도 80%인 설문에서 양성이면? → 0.24/(0.24 + 0.12) = 66.7%(실습 3).

예제 2: 황달 소견 환자 10명 중 3명이 간질환(사전확률 30%). AST 검사의 민감도·특이도는 getthediagnosis.org에서 찾아 계산합니다. 슬라이드의 함수 예는 postprobdg(0.3, 0.74, 0.92)입니다.

5. 확률분포

  • 표본분포와 중심극한정리: 모집단 평균 μ, 표준편차 σ일 때 표본 수가 충분히 크면(n ≥ 30) 표본평균은 평균 μ, 표준오차 σ/√n인 정규분포를 따릅니다.
  • 이산확률분포: 보건간호사가 맡은 50가구의 자녀 수 1·2·3·4·5명이 15·25·5·3·2가구 → 5명일 확률 2/50 = 0.04, 5명보다 적을 누적확률 48/50 = 0.96
  • 연속확률분포·확률밀도함수: 곡선 아래 전체 면적이 1이고, 두 값 사이의 면적이 확률입니다.
  • 이항분포: 성공 확률 p인 독립 베르누이 시행 n번 중 x번 성공, f(x) = nCx px qn−x. 예) 출생의 52%가 남아일 때 5명 중 3명이 남아일 확률
  • 포아송분포: 일정 시간·공간에서 드물게 일어나는 사건 수, f(x) = e−λλx/x!. 예) 응급실 평균 3명(λ = 3)일 때 2명이 올 확률
  • 정규분포: 평균 중심 대칭, 평균 = 중앙값 = 최빈값. μ ± σ에 약 68%, ± 2σ에 95%, ± 3σ에 99%. 표준정규분포는 z = (x − μ)/σ
