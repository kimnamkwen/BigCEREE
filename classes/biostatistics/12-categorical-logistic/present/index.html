12. 범주형자료분석·로짓회귀분석

Chi-square tests and logistic regression · 보건의료통계학 12주차

1. 카이제곱 분포와 검정

표준정규변수 z의 제곱은 자유도 1인 카이제곱 분포, k개 제곱합은 자유도 k인 카이제곱 분포를 따릅니다(평균 = 자유도, 분산 = 2 × 자유도). 카이제곱 검정은 관찰도수와 기대도수의 차이로 적합도·독립성·동질성을 검정합니다.

χ² = Σ (Oi − Ei)² / Ei

2. 적합도 검정

관찰 자료의 분포가 가정한 분포(균등분포, 정규분포 등)와 맞는지 검정합니다. 구간 나누기 → 관찰도수 → 가정한 분포의 기대도수 → χ² 계산 → 임계값 비교.

예제: 주사위 60번(4, 10, 7, 12, 9, 18회)이 공정한가? 예제: 병원 280곳의 병상이용률 분포가 정규분포를 따르는가? (평균 69.46, 표준편차 19.02)

3. 독립성 검정, McNemar 검정, Kappa

  • 독립성 검정: 두 분류 기준이 서로 관련 있는지. H0: 두 기준은 독립. 자유도 (행 − 1)(열 − 1). 기대도수 5 미만 칸이 있으면 Fisher 정확검정
  • McNemar 검정: 짝지은 범주형 자료(치료 전후 등). 불일치 쌍 b, c로 χ² = (|b − c| − 1)²/(b + c), 불일치 쌍이 20 이상일 때
  • Kappa: 두 평가의 일치도. K = (P관찰 − P기대)/(1 − P기대). 0.75 초과 우수, 0.4–0.75 양호, 0.4 이하 미흡

예) 치료군(treat)과 성별(sex)이 독립인가?

4. 로지스틱 회귀분석

종속변수가 이분형(가입/미가입, 이용/미이용, 건강/불건강)일 때 씁니다. 선형확률모형(OLS)은 해석이 쉽지만 예측확률이 0보다 작거나 1보다 클 수 있고 이분산이 생깁니다. 그래서 확률이 0과 1 사이에서 S자로 변하는 로짓·프로빗 모형을 씁니다.

ln{p/(1 − p)} = b0 + b1x1,   오즈비 = exp(b1),   p = 오즈/(1 + 오즈)

예) b1 = 0.2 → exp(0.2) = 1.22: x1이 1 증가하면 오즈가 22% 증가합니다.

실습: 통증 개선량(vas_1 − vas_2)이 평균보다 크면 회복(1)으로 두고, 치료군 여부로 회복을 설명합니다.
